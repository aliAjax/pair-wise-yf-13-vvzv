# hxyfront-62001 轮机值班偏差复测台

源提示词编号：1

在船舶轮机值班记录页基础上扩展的偏差复测台：轮机员按班次登记**主机转速、滑油压力、冷却水温、燃油累计**四项参数；读数越界自动开立偏差，同班同设备的后续读数只能追加复测，复测正常方可解除。所有数据保存在浏览器本地，刷新不变。

## 业务规则

| 限值 | 正常范围 |
| --- | --- |
| 主机转速 | 70 ~ 95 rpm |
| 滑油压力 | 0.35 ~ 0.55 MPa |
| 冷却水温 | 65 ~ 85 ℃ |
| 燃油累计 | 0 ~ 500 t |

- **偏差开立**：任一参数越界即生成偏差，原始读数永久保留。
- **只能复测**：同班同设备存在未结偏差时，新读数作为复测追加（第 N 次复测），不覆盖原始记录。
- **设备锁定**：复测仍越界即锁定该设备；第 3 次复测失败起，保存时必须填写失败原因。
- **解除**：复测四项全部正常 → 偏差解除、设备解锁；原始偏差与全部复测历史保留可查。
- **交接拦截**：任意班次仍有锁定设备时，交接班被拒；无锁定方可生成交接记录。
- **同步与持久**：班次/设备筛选同步作用于看板、时间线与摘要；状态与筛选偏好写入 localStorage，刷新后不变。

## 文件结构（规则 / 存储 / 界面三分离）

- `src/rules.ts` —— 业务规则层：阈值、读数保存与复测状态机、锁定判定、交接校验、时间线展开（纯函数）。
- `src/storage.ts` —— 本地存储层：localStorage 读写、版本化数据的容错恢复、界面偏好持久化。
- `src/App.tsx` —— 界面层：班次切换、参数看板、读数/复测表单、偏差复测时间线、交接班与摘要。

未新增页面，也未引入任何第三方依赖。
