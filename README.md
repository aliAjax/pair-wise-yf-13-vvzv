# hxyfront-62001 轮机值班偏差复测台

面向船舶轮机值班的单页前端系统（React + Vite + TypeScript，无额外依赖）。

## 功能

- 每班保存主机转速、滑油压力、冷却水温、燃油累计四项读数，支持多班次切换与新建。
- 同班同设备已有未结偏差时，新读数只能作为复测追加，原始越界记录不可覆盖。
- 复测仍越界即锁定设备；累计第三次失败起必须填写失败原因并留档。
- 复测全部正常可解除偏差，原偏差单与全部复测历史保留。
- 仍有锁定设备时交接被拒；支持交接备注与摘要导出。
- 设备 / 偏差状态筛选、机舱参数看板、交接班摘要、偏差时间线、正常读数历史。
- 数据与界面偏好（当前班次、筛选）均存 localStorage，刷新后不变。

## 代码结构（三个业务文件）

- `src/rules.ts`：阈值、偏差单 / 复测 / 锁定 / 解除 / 三次失败原因 / 交接校验等纯业务规则。
- `src/storage.ts`：localStorage 读写、存档校验与界面偏好持久化。
- `src/App.tsx`：单页界面（班次、看板、录入复测、筛选、时间线、交接）。
